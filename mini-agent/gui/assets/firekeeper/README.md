# FireKeeper 素材

作者：VVV。来源：https://www.aimcp.info/es/codex-pets/firekeeper-fcc21f49

## 文件

- spritesheet.webp：原始精灵图；页面元数据标注 1536×1872，单格 192×208，8 列 × 9 行。
- poster.webp：静态展示图。
- preview.webp：站点提供的横向帧条，不是自动播放的动图。
- preview.html：本地独立动画预览。直接用浏览器打开即可，无需服务器或网络。
- source-manifest.json：从作品页面提取的完整 manifest_json，保留原字段。
- pet.json：根据该元数据整理的最小本地角色描述，不是原站 ZIP 中提取的文件，也不是已验证的运行时配置。
- source.json：下载时间、原始 URL、大小、SHA-256 和帧布局信息。

## 预览边界

预览按每行 8 格循环，默认 8 帧/秒，可暂停或切换速度。动作名称、每行动作的有效帧数、时长和循环方式尚未确认；空格或重复帧可能造成停顿。9 行不应直接解释为已确定的 Harness 状态映射。
